# Instruments

Everyone has a folder here with their own copy of the starter code, already named so it opens right away.

- bella, daniel, devin, eli, enzo, liana, rafael, sunni, therese, z
- **enzo** is the example, check it out to see what changing the starter looks like

## How to use your folder

- Download the repo (green Code button → Download ZIP) and unzip it
- Open `instruments/your-name/`
- **your-name_sketch.pde** → open in Processing, hit Run, play with the keyboard
- **your-name_board.ino** → open in Arduino IDE, upload to your board
- Fill in the README in your folder with your instrument idea when you have one

## Putting your code back on GitHub

- **Easiest:** send your files to Enzo on Discord to add
- **Or upload it yourself:** send Enzo your GitHub username to get added, then on the GitHub website go to your folder → Add file → Upload files
- Only change files in your own folder so nobody overwrites anyone else
