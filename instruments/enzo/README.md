# Enzo's instrument

**Part:** bass

**Instrument idea:** synth keys or beat box on a table, pads or buttons trigger sound (undecided)

**Controls:** starter setup for now (4 buttons, 2 knobs), a s d f g h j k l on the keyboard to test

**Sounds:** bass notes in A minor, drums on the buttons

## What I changed from the starter

This is the example, so here's what making it yours looks like. Search the sketch for `CHANGED`.

- **NOTE_OCTAVE** from 0 to -1, so every note is an octave lower
- **Note length:** longer sustain and release so bass notes ring out instead of plinking

That's it. Small changes are fine. Change a setting, hit Run, listen.

## Your files

- **enzo_board/enzo_board.ino** – open in Arduino IDE, upload to your board
- **enzo_sketch/enzo_sketch.pde** – open in Processing, hit Run
- **enzo_sketch/data/** – sound files go here
